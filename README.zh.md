# 低谷待发

[English](README.md) | 中文

在输入框下方加一条极简的「低谷待发」栏：先把不紧急的问题写进队列，等 DeepSeek 进入低谷计价时段（高峰价的一半）再真正发出。

原本想现在问的问题，写完按 `Ctrl+Enter` 就放着；晚上十点不必再靠记性把它捞回来。

## 为什么是「到点才投递」

DSH 的定时任务在应用关闭期间错过的 occurrence，只会在下次启动时补投最近一次。如果入队时就把触发时间排死（`timing: {kind: 'at'}`），某次开机补投很可能落在高峰窗口，反而按全价计费。

所以这里反过来做：每 30 秒检查一次时钟，**确认当前确实处于低谷**后，才创建一个 5 秒后触发的一次性任务。周二中午入队的问题因此会在 12:00:05 发出，17:59 入队的会在 18:00:05 发出。

## 计价窗口

北京时间（UTC+8，无夏令时）：

| 时段 | 计价 |
| --- | --- |
| 周一至周五 09:00–12:00、14:00–18:00 | 高峰（全价） |
| 其余所有时间，含周末 | 低谷（高峰价 × 0.5） |
| 中国法定节假日全天 | 同样是低谷——但见下面的限制 |

插件没有内置节假日日历，因此法定节假日当天会被当成普通工作日：问题会照常在 18:00 之后发出，可能比真正的最早低谷晚几个小时，但不会多付钱。

## 用法

- **入队**：`Ctrl+Enter`，或点「排入低谷队列」。队列存在 `localStorage`（`dsh.deferredAsk.queue.v1`），刷新不丢。
- **投递**：低谷窗口内 30 秒内发出。默认目标是一个**新会话**：目录按「当前会话所属工作区 → Host 会话摘要里的 `cwd` → 面板下拉固定的目录」三级回退，下拉的固定值优先级最高。
- **追问就用「续在本会话」**：在下拉里选它（存 `"path": ""`）会**强制**在当前会话投递；选「自动选择」则解除固定。
- **失败重试**：投递失败（例如目标会话已不存在）会保留条目并指数退避重试（5 分钟起，最长 1 小时），错误原文显示在条目上。同一条目不会被并发投递两次。
- **现在发送**：按高峰价立刻发出，用于验证链路或临时改主意。
- **上限**：队列最多 50 条。

## 限制

- 折扣只对**按 token 计费**生效；包月订阅看不到价差。
- 窗口打开时 DSH **必须正在运行**；应用关着的话，下次启动后的第一个 tick 才会投递。
- 省的是单价，不是次数：同样长度的上下文搬到低谷仍是同样的 token 数，只是单价减半。因为默认开新会话，问题本身要写完整——别写「接上刚才那个 bug」。
- 30 秒的定时器只在 DSH 打开时转，不会往操作系统里排任务。

## 安装

```sh
dsh plugin --profile <profile> add dsh-deferred-ask
```

本地开发时用软链：

```sh
dsh plugin --profile <profile> add link:C:/path/to/dsh-deferred-ask
```

装好后在**插件**页出现**低谷待发**，对话输入框下方就会多出这条栏。

## 实现备注

给写 DSH 插件的人，几处容易踩的地方：

- `inject` 必须写成 `['slots', 'locale', 'remote', 'remote.schedule', 'remote.session']`：DSH 里嵌套服务要列全名，只写 `remote` 会在取 `remote.schedule` 时报 `without inject`。
- 工作目录有三条来源：`workspaces` 快照的 `items[].sessionIds` + `WorkspaceView.path`；`ctx.remote.session.list()` 里 `SessionSummary.cwd`；面板下拉（存 `localStorage` 的 `dsh.deferredAsk.target.v1`）。实测前两条在部分会话上都可能为空，所以必须有第三条。
- 下拉的三态要分清：**没有 key** = 未固定（用自动解析结果）、`{"path": ""}` = 明确要求续在本会话（**覆盖**自动解析结果）、`{"path": "D:\\..."}` = 固定到某个目录。早期版本把「空字符串」当成「没固定」，于是选了「续在本会话」仍被自动解析出的目录覆盖，仍会新开会话。
- 该槽位给的选择器 hook（`useWorkspaces` / `useSession`）签名是 `<S>(selector, equals?) => S`，无参调用会抛错——这也是为什么目录不靠它们取。
- 面板挂在 `conversation.composer.dock`（输入框下方），另在 `shell.overlay` 挂一个浮动窗口作为兜底：dock 没挂上时也能操作队列。`shell.overlay` 是 root 作用域、props 里没有 `sessionId`，所以浮窗里只能「固定目录 / 自动」，选「续在本会话」会被拒绝并提示，不会静默改成新会话。
